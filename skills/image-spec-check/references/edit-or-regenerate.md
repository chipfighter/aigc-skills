# 修图还是重新生成

- **修图**：机位和构图不变，只改局部，比如手、道具、表情、颜色，去掉或加上一个小物件。底图用版本表里的"当前底图"，不用刚失败的那张，因为在失败的图上接着改，错误和走样会累积。提示词里写明哪些地方必须保持不变。
- **重新生成**：机位或景别变了、姿势大幅变化、同一处修了两次还不对，或者连续修图后画面开始走样，都重新生成。修图模型会尽量保留原图的布局和透视，换机位时改不动遮挡和透视，结果常常是扭曲的。重新生成时把当前底图作为人物和服装参考，写明只参考长相和服装、不参考构图；机位在哪、人物与场景的前后左右关系要重新描述。

修图改光线、画风，或者补出原图外的结构（比如把画面外的桌角补进来）时，修图模型常把没要求改的地方一起改坏：对比测试里，调暖光时把黑发染成了棕色，补桌角时带出了透视错误。这类修图的提示词要列出必须保持的颜色和结构，核对时专门和上一版对比这些地方。
