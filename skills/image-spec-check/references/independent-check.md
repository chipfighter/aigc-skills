# 独立核对（用户要求时才做）

用户说要"严格核对""独立核对"时，才另开一个子代理核对：

- 只给它 `清单.md` 和图片路径，不给提示词和对话。让它把每条结论和依据直接写在回复里，由主代理存进 `核对记录.md`。子代理的环境常常没有写文件的权限，让它去存文件只会白白耗时间。
- 由主代理按清单每条的"看"先把局部裁好，把裁切图路径和原图一起交给它。
- 工具允许设置的话，用低推理强度：核对主要靠看，用不着多少推理。模型可以比主代理低一档，但要能看清手指、饰品这类细节，不要用太小的模型。

默认不开子代理，是因为在一次对比测试里，独立核对子代理漏到用户面前的问题并不比主代理自检更少，Claude 的 token 却多用了约 1.5～2 倍，有时还比用户更严，白白多走几轮。
