# 关键帧（只用单首帧）

默认用全能参考，原因见 SKILL.md。

- **关键帧只在下面三种情况使用。**
  1. 用户明确要求，或已确认的分镜把某张图指定为视频开场必须出现的画面。图要落在中段或结尾时（例如推镜最后必须停在某个构图），不做成关键帧，按 [生成单位、剧照和接戏](shots-and-joins.md) 里的「构图剧照」挂成普通参考，写明到哪个动作或时刻达到这个构图。单纯认可预览、机位或视觉方向时，预览图用于沟通，制作时如有需要可用作普通参考。
  2. 这段镜头里有某一处必须稳定，而只靠素材和文字锁不住。属于[模型易错点](model-pitfalls.md)里写明要用开场画面解决的问题时直接用，例如要露字的镜头。开场必须是某个具体姿态或状态（人已经跪着、手已经按在门上），也可能属于这种情况：Scenario 在它的接口上观察到，全能参考的开场可能沿用参考图里的原始状态，文字写的开场姿态出不来（社区经验，我们没验证过）。
  3. 同一片段生成后，失败在关键帧能锁住的东西上：构图、道具的位置和状态、画面里的字。重新生成时可以加关键帧。表演不自然、动作发僵这类失败，关键帧解决不了，反而容易更僵，不换成关键帧。

  不要只凭"感觉模型可能做不好"就预先用关键帧：说不出具体哪一处要锁、为什么素材和文字锁不住，就按默认。决定用关键帧后，写清对应图片和片段。
- **关键帧只用单首帧，不用首尾帧。** 首尾帧做出来的效果往往不好，高赞作品的剧情镜头里也基本不用；尾帧和中段关键帧同样不用。要求中段或结尾达到某个画面时，用构图剧照作普通参考，或用文字交代运镜的起止构图。提示词里把参考图写成"第一帧的机位、构图、姿态都和这张图一样"，效果上也是首帧，同样按上面的条件判断该不该这样用；几次生成之间接戏的写法见 [生成单位、剧照和接戏](shots-and-joins.md)。
- **用于视频生成的关键帧按 [参考图](reference-images.md) 里全身多视图的规则遮脸。** 主要人物或用户明确提到的具体人物露脸时，盖住面部。仅作背景的路人、群演等人物可以保留面部。首帧和构图剧照都适用。保留头部朝向、人物姿态、构图和光线。为需要遮脸的人物分别附上独立的面部近景，并在提示词中写清成片何时露脸、当时的表情和视线。图上的遮挡仅用于参考素材，提示词里写明它只是标记、视频里不要出现，例如"图上脸部的灰色方块只是遮挡标记，她的长相按面部近景"。附带的好处：带写实人脸的开场画面可能被平台退回，遮住脸的通常能过（Seedance 2.5 实测）。
- 关键帧会约束该时刻的构图、姿态和光线，也可能影响画面中可见的表情。图片中的瑕疵也可能被继承，模型为贴合指定画面还可能压缩中间动作或使动作生硬。使用前检查图片和上下文是否相容。需要生成关键帧图片时，用不用 SVG 辅助生图按 [构图小样](../../storyboard-preview/references/composition-sketch.md) 的标准判断。
- 首帧选稳定状态：动作开始前，或动作完成后的停顿；表情在起点而不是峰值。不选动作进行中、半眨眼、话说到一半、头发或衣角正飘起的瞬间，否则模型要猜动作方向和速度，开头容易顿挫或变形。动作接动作的剪辑可用上一段视频截出的真实帧，并写清动作继续的方向；已经在走、在跑的跟拍可以从中途开始。首帧投喂前检查姿态、手、透视、光线与环境是否相容，有问题先修，修不好就改作普通参考或不用。图片作为普通参考时写明只参考什么，不等于作为首帧。
