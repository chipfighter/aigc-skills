# 参考图怎么准备

素材按实际用途选，先复用能满足本段需求的，再补会影响成片的缺项；每份素材写清编号和用途（见 SKILL.md）。

## 人物参考图

- 主要人物和用户明确提到的具体人物，长相只用独立的面部近景参考，通常先用一张清晰的正面近景。已有清晰的面部近景可直接用。全身多视图用于交代体型、发型轮廓、服装和配饰。主要人物和用户明确提到的具体人物在图里露脸时盖住面部：多视图里的小脸常和面部近景看着不一样，模型可能当成两个人，所以长相只从面部近景取。仅作背景的路人、群演等人物可以保留面部。需要新做全身多视图时，可按造型选正、侧、背三视图；背影、侧面镜头多的片子，背面和侧面要有。服装或配饰左右不对称时，保留左右两侧。各格全身等大、头脚对齐，统一背景和光线，动作中性，剧情道具交给提示词。头部不出镜的配角，只准备镜头实际需要的造型参考。
- 镜头需要稳定呈现转头，或会清楚露出某个需要保持一致的头部角度时，再以已确认的正面近景补所需角度的头部近景，例如斜 45°、正侧或后脑。可以分开出图，也可以把正面和需要的其他角度排在同一张大图里，每格独立且头部清楚。按机位核对转头后露出的是哪一侧。侧脸、四分之三侧脸是镜头主体时也属于这种情况：只给正面近景，模型会自己推侧面长相，几个镜头之间容易不像同一个人。只准备当前片段会用到的角度，避免在生成前一次性出齐，额外消耗 token。
- 反复出场的非人角色（龙、怪兽、动物、机器人）也按镜头准备角度参考。它们没有遮脸的问题，但形体更容易被模型自己编：背面、腹面、俯视看到的背脊，以及飞、跑、游这类运动姿态，只给一张侧面设定图，模型会自己推，几个镜头之间对不上。镜头会清楚露出哪一面、哪种姿态，就补那一面或那种姿态的参考；体型在片中会变的，每个体型阶段各有参考。和人物一样，只准备当前片段会用到的。
- 多份人物参考尽量统一光色和状态。人物参考用中性表情和姿态，除非某个状态本身就是指定的参考内容。

## 表情参考和连续动作

写实和 2D 都默认用中性参考加文字表达处境、表演和表情变化；把表情变化写成动作过程。关键帧里面部被盖住时，用文字交代成片在该时刻应呈现的表情。2D 里文字难以稳定复现的画风表情，可补表情参考，并写明只参考表情画法。连续动作需要更高精度时，根据连续感、准确度和预算，选择概括生成、拆成多个片段，或使用导演台、灰模动画、表演视频参考；不默认靠继续加长文字解决，也不默认要求用户额外制作。用户已明确要求多种参考时照做，不强制先做减法。

## 俯视图和白模

用户已判断或指定是否使用俯视图、白模时，沿用其选择；未指定时由助手判断。简单场景沿用文字和已有素材；空间关系复杂或反馈反复出现站位错误时，主动考虑辅助参考，并简短说明要解决的问题。俯视图用于明确站位与布局，白模按需控制连续移动、运镜和遮挡变化，不作为固定前置步骤。
