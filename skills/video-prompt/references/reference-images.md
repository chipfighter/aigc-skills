# 参考图怎么准备

素材按实际用途选，先复用能满足本段需求的，再补会影响成片的缺项；每份素材写清编号和用途（见 SKILL.md）。

## 人物参考图

主要人物和用户明确提到的具体人物，写实、动画、3D 都一样，固定准备两张图，长相只从第二张取：

1. **全身多视图一张**，交代体型、发型轮廓、服装和配饰。按造型选正、侧、背；背影、侧面镜头多的片子，背面和侧面要有。服装或配饰左右不对称时，保留左右两侧。各格全身等大、头脚对齐，统一背景和光线，动作中性，剧情道具交给提示词。图里的脸盖住：全身图里的脸小，生成时容易被压缩走样，和头部近景看着不一样，模型可能当成两个人。
2. **头部多角度图一张**：一张大图里排四格，每格等大、头部占满格子：正面、左斜 45°、右斜 45°、正侧。只给正面，模型会自己推侧面长相，几个镜头之间容易不像同一个人，所以默认就排齐。斜 45° 两个方向都排：它是对话戏里最常拍到的角度，正反打两边都会出现。正侧排一侧就够：脸大致左右对称，模型能推出另一侧。下面两种情况加格子，排成六格：
   - 脸或发型左右不对称（偏分、痣或疤、单侧耳饰、一边头发别在耳后）：另一侧的正侧也排上。
   - 发型复杂（发髻、辫子、发饰）或者过肩镜头多：加一格后脑。过肩镜头里前景人物的后脑占画面很大，全身多视图的背面太小，看不清发型细节；发型简单时用全身图的背面就够。

   按机位核对转头后露出的是哪一侧。已有清晰的正面近景时，用它当正面那一格。其他文件说的"面部近景"，指的就是这张图。

- 不要一个角度单独出一张。角度在角色定稿时一次排进头部那张；之后才发现缺某个角度，以已确认的正面近景为底单独补那一格，不重做整张：重做时正面也会跟着变。
- 一次生成里角色多、参考图位置不够时，两张可以合成一张：左边头部各格，右边遮了脸的全身视图（社区常见的排法）。合成后头部各格不能缩得太小，放不下时头部只留正面和两个斜 45°。
- 仅作背景的路人、群演等人物可以保留面部。头部不出镜的配角，只准备镜头实际需要的造型参考。
- 反复出场的非人角色（龙、怪兽、动物、机器人、拟人角色）也是两张，一律不遮脸：全身多视图一张；细节图一张，放头部和近景里会被看清的部位（花纹、眼睛、牙爪等）。它们的形体更容易被模型自己编：背面、腹面、俯视看到的背脊，以及飞、跑、游这类运动姿态，只给一张侧面设定图，模型会自己推，几个镜头之间对不上。镜头会清楚露出的面和姿态，排进这两张里，排不下的再单独出。体型在片中会变的，每个体型阶段各一套。
- 多份人物参考尽量统一光色和状态。人物参考用中性表情和姿态，除非某个状态本身就是指定的参考内容。

## 表情参考和连续动作

写实和 2D 都默认用中性参考加文字表达处境、表演和表情变化；把表情变化写成动作过程。关键帧里面部被盖住时，用文字交代成片在该时刻应呈现的表情。2D 里文字难以稳定复现的画风表情，可补表情参考，并写明只参考表情画法。连续动作需要更高精度时，根据连续感、准确度和预算，选择概括生成、拆成多个片段，或使用导演台、灰模动画、表演视频参考；不默认靠继续加长文字解决，也不默认要求用户额外制作。用户已明确要求多种参考时照做，不强制先做减法。

## 俯视图和白模

用户已判断或指定是否使用俯视图、白模时，沿用其选择；未指定时由助手判断。简单场景沿用文字和已有素材；空间关系复杂或反馈反复出现站位错误时，主动考虑辅助参考，并简短说明要解决的问题。俯视图用于明确站位与布局，白模按需控制连续移动、运镜和遮挡变化，不作为固定前置步骤。
