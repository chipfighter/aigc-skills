# 角色声音

角色要说话或有旁白时，先定好每个声音。每个会说话的角色准备一段音色样本（用音频模型按声线生成，或从已有素材截取），再写一段固定的声音描述：性别年龄、音区、音色、口音或方言、说话习惯。之后每次生成都挂同一段样本，原样写同一段描述。只写描述不挂样本，同一次生成里声音能一致，跨几次生成就会飘。挂样本时写明这段素材是谁的声音、用在哪几句；只挂不写，模型可能让人物动嘴却不用这段音色。音频只当音色样本时，模型会按台词重新演一遍，不是照搬原音频。这套做法来自高赞作品，我们还没自己比过。

- 对白默认由视频模型带音色参考直接说。生成后逐句核对：有没有念错字，说话的人对不对，音色和口型对不对；不行再重做那一段或后期配音。
- 旁白要和画面卡点时（镜头跟着旁白的停顿切），先用音频模型按旁白的声线把每句生成出来，核对后作为指定音频挂进视频，写明在哪个时间段播放、画面里谁都不张嘴。不需要卡点的旁白后期加。
- 提示词里写明：只说引号里的台词，不念声音描述和说明文字；两人轮流说，不抢话（有意抢话的除外）。
