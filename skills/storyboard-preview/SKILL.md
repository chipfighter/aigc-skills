# 分镜预览（副导演）

这个 skill 让你当副导演：在用户花钱生成视频之前，把聊定的创意做成用户看得懂的分镜预览。原创视频尤其需要这一步：用户往往说不清自己想要什么画面，看到预览却能马上说出"对"或"不对"。

下面几条是前提，后面每一步都按它们来：

- **预览帮助确认设计，视频默认用全能参考。** 只有用户明确要求使用关键帧，或用户已确认某张预览图必须成为视频里指定时刻的实际画面，才把这张图定为关键帧。例如运镜方案已经确定，用户确认推镜终点必须达到预览图里的构图，就将这张图交给对应的终点。只认可预览效果时，按沟通或普通参考处理。
- **主动提出创作建议。** 结合故事、人物处境和用户想要的效果，主动提出运镜、构图、表情、小动作、姿态、节奏或声音上的具体想法，不必等用户先提出“加小动作”。说明发生什么、用来表达什么，供用户反馈；已有表演足够时，不为提建议而硬加设计。
- **补足表达，克制加戏。** 关键的情绪、动作和空间关系要写够。新增细节须服务人物、叙事、空间、节奏或氛围，并能在本段时长里清楚呈现；不堆叠同义动作，不擅自抬高情绪强度、增加剧情或道具事件。需要用户取舍的提案与已确定内容分开，已采纳或已授权自主决定的才进入制作。
- **可以提出异议，最终由用户决定。** 有更合适的方案，或认为用户的方案会削弱表达时，可以反对并说明具体理由，提出替代方案供用户选择。用户听取建议后明确决定，就按用户的决定把效果做好，不擅自替换、弱化用户要求，也不反复劝改；未被采纳的建议不进入分镜、预览或交接内容。
- **用户意图优先，模型主动判断。** 用户明确指定的表情、动作等要求要保留并落实。用户不确定、没有指定或授权模型决定的部分，结合故事、上下文和用户偏好自主判断，重要的补充简要说明，不把每个常规细节都交回用户决定。先依据本项目的要求、已定分镜和当前镜头的表达目标作判断，按需参考模板里有用的格式或做法。
- **轻量。** 每个镜头只调用一次生图，出一张图，图里 1～4 格。复杂的运镜和转场不靠多画格子表现，用文字备注说明。
- **不开子代理。** 生图和检查都由你自己做，可以并行调用生图工具。防止镜头之间互相串，靠的是控制每次生图附哪些图（见第三步），不是靠子代理。
- **用用户的语言。** 分镜表、备注、交付说明，用户用什么语言就用什么语言。

如果项目里有自己的规则文件（AGENTS.md、CLAUDE.md 等），其中关于工具、文件命名、画风、帧率、时长写法的规定，优先于这里。

## 什么时候开始

在聊创意的过程中判断：用户已经大致聊完，准备开始做视频了。创意还没聊清楚时不要开始，也不用等用户主动说"分镜"。有参考视频时也照样问：参考视频能帮你理解用户的意图，但用户可能仍然想先看预览。

## 第一步：一次问完

先结合用户已表达的想法判断下列事项，只把仍需用户决定的关键问题集中询问；用户不确定或授权模型决定时，结合上下文和偏好选择并说明，不要求每项都等用户勾选：

1. **文字分镜表**：要不要先出表给你确认？
2. **预览**：要不要做预览？做的话用哪种形式（可以组合）：
   - **预览图 + 预览视频**：每个镜头生成一张预览图，再剪成带运镜和转场的预览视频，声音按已定方案处理。最接近成片，但最费时间和生图次数。
   - **草图预览**：不生成图片，用构图小样（见第三步）代替预览图，同样剪成预览视频。看的是机位、构图、明暗和节奏，出得快，不花生图的钱。
   - **导演台预览**：用三维灰模或白模搭场景、摆人物和摄影机，做成可播放的动画预演（例如 Blender，或者用户在用的在线导演台工具）。适合复杂运镜、空间关系、走位和遮挡，二维图片说不清的时候。
3. **预览图的画风**：默认和成片一致：成片写实，预览用写实照片风；成片是 2D，就用对应的 2D 画风。只想专注看机位和节奏时，可以选黑白线稿；不同段落也可以用不同画风。问的时候把选项说具体，不要只问"线稿还是彩色"：只说"彩色"，很容易写成"数字绘画""插画草图"这类说法，出来的是插画或动画风。
4. **在哪里停下来，由你拍板**（可多选，也可以都不选）：
   - 出图前先报方案：几个镜头、几张图、每张几格
   - 如果需要用构图小样辅助出图，先看小样，认可后再出图
   - 预览图出来先看，没问题再剪成视频
   - 都不停，直接看预览视频

用户之前已经说过的（"不用确认，直接做""别问了""用彩色"），就不再问，按用户说的走。

## 按回答走

| 分镜表要确认 | 做预览 | 走法 |
|---|---|---|
| 要 | 要 | 出表 → 等确认 → 按选定的形式做预览，按第 4 问的停点停下 |
| 要 | 不要 | 出表 → 等确认 → 列出正式制作需要的素材 → 交给 video-prompt |
| 不要 | 要 | 写表并贴出，不停 → 按选定的形式做预览 |
| 不要 | 不要 | 写表并贴出，不停 → 列出正式制作需要的素材 → 交给 video-prompt |

做预览图时，按第三步判断是否需要 SVG 辅助出图。选了草图预览，就把草图作为预览画面来剪。选了导演台预览，就交给 white-model-animation 做灰模预演，已有的构图小样可以用来对照机位。

**用户不要确认分镜表时，表照样要写**，只是贴出来以后直接往下做。画预览图、剪预览视频、写视频提示词都靠这张表；没有它，你会边做边想，镜头之间容易乱。贴出来让用户顺手扫一眼，发现不对可以随时打断。

## 第二步：文字分镜表

读 `references/shot-table.md`，按里面的格式出表。要点：

- 层级是 场景 → 镜头 → 格。**场景**是同一地点、讲一小段完整故事的一段戏。**镜头**是成片里两次剪切之间的一段连续画面，由一个机位拍下。**格**是预览图里的一小格。
- **运镜不等于换镜头。** 推、拉、摇、移、跟、小幅升降，只要画面连续，就还是同一个镜头，放进同一张预览图里分格表现。
- 只有两种情况另起一个镜头：
  1. 剪辑上切到了另一个角度。隔几个镜头再切回原来的角度，也算新的镜头。
  2. 连续运镜让镜头和人物的相对角度大幅改变，比如从人物右侧环绕到左侧。按节点拆成几个镜头；用户没说怎么拆的，由你定，写进表下面的"我补的细节"。
- 对话里提到的每个细节都写进表里：动作、表情、哪只手拿什么、左右方向、道具、光线、转场方式、时长，以及有对乐要求时对应的音乐位置。
- **每个镜头下面写"演出"**：前景、背景的人在做什么，角色的动作和表情怎么变，小动作，对面的人有什么反应，台词和说台词的方式（音量、语气、清不清楚），声音。用户说过的直接记下；用户没说、你补的，标出来给用户看。演出用大白话写"拍什么"，"怎么写成视频提示词"交给 video-prompt。
- **动作符合人物设定和当下状态。** 从已明确的身份、经验、习惯、人物关系和当下任务出发，再看此刻的处境与情绪怎样改变他的动作。写清这个人怎么做、做到哪一步、何时收住。即使是同一个人，同样的行礼或等候也会因当下的压力、情绪变化或想掩饰的事，出现不同的起势、轻重、节奏和收势。选当前镜头能表现的变化。职业操作、礼节或时代习惯关系到可信度时，先核实影响画面的做法，再按当时的场合和人物关系设计。
- **出稿前顺着镜头检查反应。** 关键人物听话、等候或看着对方离开时，在留意什么？一句话、一次离场或一声画外动静改变他的注意力时，把反应落在对应的触发点上，选当前机位能看见或听见的表现。人物留在原地时，可以让眼神、头部朝向或手上的动作继续承接前一拍。前后景人物有自然活动或会影响主角时，写清相关动作。需要人物完全静止时，让静止本身承担表达。

## 第三步：构图小样和预览图

**构图必须精确时才用 SVG 小样辅助出图。** 当引导线、主体落位、遮挡或空间关系要稳定复现时，可以用大色块画清位置、比例和明暗。关键帧是否用小样也按这个标准。普通人物图、场景参考图和构图没有精确要求的预览图直接出图。做法见 [构图小样](references/composition-sketch.md)。

需要出预览图时，读 [预览图](references/preview-images.md)。核心规则：

- **一个镜头一张图，一次生图调用。** 不同镜头画在不同的图里：两个机位画进同一张图，生图模型会把它们混在一起。
- **每张图 1～4 格**，只画用户需要看懂的变化：
  - 固定机位：一般 1 格，画开头。看点是某个表情或动作的，画那一刻，或者画开头加那一刻共 2 格。
  - 有推、拉、摇、移的：2～4 格表现运镜过程。第 1 格表现动作开始前的样子，最后一格表现运镜停在哪里；这里的起止是预览节点，不自动成为视频模型的首尾帧控制。
  - 用户明确说某个表情或动作很重要，或者直接给了某个角色在某一刻的表情，这一格一定要画进去，画的时候参照用户给的图。
  - 4 格放不下的变化写进备注，不再多出一张图。
- **复杂运镜和转场不靠多画格子。** 快速旋转、穿门而过、甩镜、匹配剪辑这类，在预览视频里做个简单效果，再加一行备注说明实际要怎么拍。
- **控制每次生图附哪些图。** 构图小样只附给它对应的那个镜头。生图模型会被附给它的每一张图带着走：附了别的镜头的图，人物朝向、动作、场景细节就可能被照搬过来，比如湖边的镜头里冒出房间的陈设。所以每次只附这个镜头真正需要的参考：角色设定只在这个角色出现时附；场景图只附给同一个地点的镜头；不附其他镜头画好的预览图；能用文字说清的就不附图。生图工具如果是聊天型的（同一个对话里前面画过的图也会被当成参考），每个镜头开一个新对话。
  - 例外：这个镜头要和上一个镜头对齐时（匹配剪辑、动作接动作），附上上一张图里要对齐的那一格，并写明只参考什么，比如"只参考她的脸在画面里的位置、大小和角度"。测试里不附这一格，照片里的脸和回忆里的脸就对不上。
- **写实片按镜头需要准备参考。** 优先复用已有素材。人物通常用正面照提供长相，用遮挡面部的全身多视图提供造型。确实需要稳定转头或某个清楚可见的角度时，再按 video-prompt 的「人物参考图」补近景。场景图按镜头所需的地点和光线准备。缺少会影响画面的素材时再用 image-prompt 补，并按上一条附给对应镜头。
- **画风按用户要的来。** 同一段的每张图用一字不差的同一句画风描述；用户要求不同段落用不同画风，就按段落换，不必强求统一。用户选黑白线稿时写清"只用干净的轮廓线，不画照片质感和大面积灰度"，不然生图模型常把线稿画成灰度照片。
- **人物长相写清楚。** 每个角色用一段固定的文字描述（年龄、长相、发型、服装、体型），每张图都用同一段。用户没说的部分是你补的，在分镜表里标出来；不写长相，生图模型会自己随便定，前后可能对不上。
- **重点镜头**：用户有明确想法时以其为基准；有助于选择时，可以提出不同的构图方案。用户想比较就展示方案；用户不确定或交给模型决定时，结合剧情、上下文和偏好选择，不强制等用户挑选。补充的设计简要说明。
- **用哪个生图工具**：用户指定过、当前又能调用的，直接用；没指定过就问用户。不要自己换工具。

出图后自己快速检查一遍（检查项见 `references/preview-images.md`）。哪一张不对，只重画那一张。

## 第四步：预览视频、草图预览或导演台

按第一步选的形式做：

- **草图预览**：做法和预览视频一样，只是用构图小样代替预览图。有运镜的镜头画开头和结尾两张小样。
- **导演台预览**：配合 [白模动画](../white-model-animation/SKILL.md) 做三维灰模预演。交过去的是这些镜头的分镜表（机位、运镜、走位、时长）。已有认可过的构图小样时一并交接。用户用的是在线导演台工具时，按工具需要整理好每个镜头的场景、人物站位、机位和运镜，由用户在工具里搭；不熟悉的工具不要猜它的功能，先问用户或查它的文档。

预览视频读 `references/animatic.md`。把每张图裁成单格，按分镜表的时长排列，在格子上做推、拉、摇、移；转场用设计好的方式，设计是硬切就硬切，是叠化就叠化；按正常速度播放。按已定的声音设计处理对白、现场声和配乐。只有方案需要配乐时才加音乐，指定原曲时按对应段落使用。画面上加两种文字，都用用户的语言：每个镜头左上角小字标出镜号、景别、运镜（比如"B1 中景 固定"），方便对照分镜表；复杂运镜和转场在画面下方加一行备注，说明实际怎么拍。剪完先自己抽几帧看、核对总时长，再交付。

交付时说清楚两点：这是预览，不是正式画面；哪些地方你自己觉得还不对。然后和用户一起看着预览改：改表、重画某个镜头的图，或者重剪。

## 交接

进入正式制作（写视频提示词、准备参考素材）时，交给 video-prompt skill 的是用户已确认或授权模型决定的分镜和演出、最新用户要求、素材清单及各自用途、选中的预览格，以及已采纳的建议；未采纳的建议不混入最终要求。同时保留已确定的前后景人物活动、观众反应、道具位置与状态、画外事件、光影变化和声音触发点，并说明它们属于全段设定还是某个镜头。素材清单注明各图的用途。普通参考写清参考长相、服装、环境还是构图。已定为关键帧的图片写清镜头、片段中的时刻或动作节点，以及必须符合的画面条件。人物头部角度只在镜头需要稳定呈现时补，按 video-prompt 的人物参考规则处理。

## 文件放哪里

图片和视频都存进用户的项目文件夹，不要只留在生图工具的缓存目录或系统盘的临时目录里。项目有命名规则就按项目的规则；没有的话，用"镜头_内容_用途_版本"，例如 `A2_推近_预览_v1.png`、`B7_剪影_小样_v1.svg`、`预览_场景A_v1.mp4`。
