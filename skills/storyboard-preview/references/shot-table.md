# 文字分镜表

分镜表有两个用途：给用户确认"你要做的是不是我想的"；给你自己当施工图，后面画预览图、剪预览视频、写视频提示词都按它来。所以表里要写到能直接拿去画图的程度。

## 先写场景概览

每个场景用两三行交代清楚：

```
场景 [编号]：[地点、时间、光线和本场发生的事]
人物：[出场角色及已有设定，补充项标为“AI 补的”]
质感和氛围：[本场画面质感与气氛]
预览画风：[按实际方案填写]
```

每个角色的描述写一次，后面每张预览图都用同一段，前后才对得上。

## 再写分镜表

每行一个镜头。一个镜头 = 一个机位拍下的一段连续画面 = 一张预览图。

| 镜头 | 机位（景别、角度） | 运镜 | 画面内容 | 预览格 | 转场到下一镜 | 时长 | 音乐位置 | 备注 |
|---|---|---|---|---|---|---|---|---|

各列怎么写：

- **镜头**：场景字母 + 序号。同一个角度隔几个镜头再回来，算新的一行。
- **机位**：景别（远景、全景、中景、近景、特写）、角度（平视、仰、俯、侧面、背面），以及人物在画面里的位置。同一行里这些不变，变化只来自"运镜"这一列。
- **运镜**：固定、推、拉、摇、移、跟、升降、环绕。写出方向和快慢，例如"镜头随人物向左平移，较慢"。大幅环绕按节点拆成几个镜头，每个节点一行。
- **画面内容**：动作按发生顺序写，再写表情变化；持物写清楚哪只手拿着什么，用靠近物体那一侧的手；朝向写清楚左还是右（以画面为准）。有路、走廊这类有方向的环境时，写清它在画面里怎么走，人物的移动方向要和它对得上。对话里用户提过的细节一个都不漏。
- **预览格**：写清每格画什么（1～4 格），例如开头、中间、结尾或看点出现的时刻。怎么选格见 SKILL.md 第三步。用户强调过的表情、动作，标「用户强调」。不做预览时，这一栏写制作需要的素材，默认按全能参考列出。只有用户明确要求关键帧，或已经确认某张图必须是视频里的指定一帧，才记为关键帧，并标出图片、时刻或动作节点。
- **转场**：硬切、叠化、黑场、白闪、甩镜、擦除、匹配剪辑、遮挡转场等。设计了特殊转场的，写清楚靠什么衔接，具体到前一镜结束和后一镜开始的画面。
- **时长和音乐位置**：时长按镜头节奏和项目要求分配。需要对乐时才填写音乐位置，并核对镜头时长和对应的音乐段落。项目对时长写法有规定的（比如只写整数秒），按项目规定写。
- **备注**：复杂运镜和转场实际要怎么拍（预览视频里只能做个简单效果，这里说清楚真实的样子）；4 格放不下的变化也写在这里。

## 每个镜头下面写"演出"

用大白话写这个镜头里"拍什么"，每条后面标来源：

```
[镜号] 演出
- 前景：[可见内容和活动] ｜[来源]
- 背景：[可见内容和活动] ｜[来源]
- 动作和表情：[变化及触发点] ｜[来源]
- 小动作：[与人物和当下处境相关的细节] ｜[来源]
- 对面的人：[反应] ｜[来源]
- 台词：[内容和说法] ｜[来源]
- 声音：[音源及出现时机] ｜[来源]
```

- 用户说过的直接记下，标"用户"；用户没说、你补的，标"AI 补的"，方便用户一眼看出哪些要改。
- 没有的项写"无"，不为了显得丰富硬加。
- 用户的情绪原话（"下定决心""强忍着"）保留。把它补成看得见的动作时，标明是你补的。
- 表演强度按想要的分寸写。预览图和视频模型都会照字面演："笑弯了腰""笑得直不起腰"会画成张大嘴的大笑。想要收着的，就写收着的样子，比如"忍不住轻笑，嘴张得不大"。
- 这里只写拍什么。怎么写成视频模型听得懂的提示词，交给 video-prompt。

## 写完自查空间关系

表写完、出预览之前，按场景自查下面四项。这些错在文字里不显眼，画出来或生成出来才露馅：

- **机位看不看得到写的东西**：侧面机位拍不到背影，背后机位看不到表情。
- **光从哪来**：以建立镜头里光源（太阳、窗、灯）的实际位置为准，推出每个机位里光从画面哪一侧来。换到反方向的机位，逆光会变成顺光。
- **左右按人物或载具自己的记**：座位、站位写成"她坐在船的右边（以船头为前）"，每个镜头再按机位换算画面左右。从正面拍和从背后拍，画面左右正好相反。
- **跨镜头的路线**：人或载具连续几个镜头在移动时，用画面里的地标写清从哪来、往哪去，比如"船刚离开亭子，往下游划"，每个镜头的朝向都跟着这条路线。

## 表下面列出你的假设

演出以外、你替用户定下的东西，单独列出来，方便用户一眼看到要不要改：

```
我补的细节：
- [镜号] [自主决定的拍法或补充细节]
```
