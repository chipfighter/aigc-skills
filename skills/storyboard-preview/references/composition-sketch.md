# 构图小样（SVG 明暗小样）

构图小样是一张用 SVG 画的、只有大色块的示意图。需要稳定出图构图时，将小样作为生图参考。它解决两个问题：

- **用户看不懂文字描述的构图。** "人在右三分、身后满屏虚灯、左下有火盆"，说十句不如看一眼。用户看着小样能直接说"人往左一点""这块再暗一点"。
- **只靠文字时，生图模型的位置和明暗容易跑。** 附上小样以后，人物位置、大小、亮暗分布基本能落位。

小样只管构图和光，不管好不好看。画得越像画，越容易把模型带偏。

## 什么时候画

构图复杂就画，简单的出图不画。画小样不花积分，换来的是构图稳定落位，值得。

**默认画**，满足一条就画：

- 画面里有两个以上要落位的人或物，比如两人的站位和距离、人和关键道具的位置关系。
- 有前景遮挡，或者前、中、后景好几层要分开。
- 人在画面里要有特定的大小或位置，比如大远景里只占画面高度十分之一、站在右下三分点。只靠文字，模型常把人画大。
- 有人群结构或纵深引导线：人群让出一条通道、分成几组、主角必须在人群里露出来；路或走廊往哪个方向延伸。人群只是质感（"街上人很多"）时不算。
- 特殊机位：高俯、极低、贴着某个表面拍、框中框。
- 已经失败过一次：核对时有一条布局要求没通过。布局问题换个说法很少有用，重新生成时加小样，不改写提示词再抽。

**不画**：

- 单人或单物的设定图、三视图、面部近景，只交代地点长什么样的场景参考图，以表情和动作为主的近景、特写。已有清楚的构图参考时直接用。
- 内容上的错误，比如画面里多了字或标志、姿势类型不对、真人感不够。小样只管位置、大小和明暗，解决不了这些。

画之前先写出它要固定的布局要求，每条都能写成 image-spec-check 清单里的一条，例如"主角在大远景里只占画面高度约十分之一，站在右下三分点""人群中间让出一条通道，从左下通向画面中央""两组人被柱子隔开，只有她露在亮处"。画面里只画这几条关系。写不出具体的位置、大小、遮挡或走向，说明构图其实不复杂，不画。

小样主要用来辅助出图：画好、自查后直接作为生图参考，不停下来等用户看。用户要求先看构图时，先给用户看；用户专门选了草图预览时，小样同时就是预览，视频素材仍按分镜交接规则选择。

## 一张小样只讲一件事

一张小样只画一个瞬间、一组关系。前景、中景、背景最多三层，彼此错开，不要压在同一块地方。要表现变化（例如舞队擦过以后人不见了），画成前后两张，不要挤进一张。

（测试里三层叠在一起的小样，用户完全看不懂；改成两人朝镜头走来、前景一人擦过，一眼就懂了。）用户看不懂的小样，生成出来的画面观众也看不懂。

## 画什么

一张小样只交代四件事：

1. **主体在哪、多大。** 人物用简单剪影：头一个圆，身体一个梯形或几段折线。站位、朝向（侧身、背对、正面）、大致姿态（抬手、低头）从轮廓上要读得出来。大小按机位算，不要凭感觉：人在画面里的高度约等于"焦距 × 身高 ÷（距离 × 画幅高度）"，全画幅的画幅高度横屏和方屏按 24mm 算，竖屏按 36mm 算。例如 135mm 镜头、人站在 10 米外，1.75 米高的人约占画面高度的 98%。
2. **大块明暗。** 整张图用 3～5 个明度层次：最暗、暗、中、亮、最亮。先铺背景的大明暗，再铺光照到的区域（灯下的一团光、窗投下的一块光），最后放主体。主体要和身后的背景分得开：亮背景前的暗剪影，或暗背景里的亮人。
3. **光从哪来。** 光源本身画成亮块（一团灯、一扇窗、一个火盆）；主体受光的一侧用一条亮色细线示意轮廓光或受光边。冷光和暖光可以各用一种颜色（例如冷蓝的月光、暖橙的灯火），其他地方都用灰。
4. **前景和遮挡。** 虚掉的前景（路人、栏杆、门框、火盆）画成大块深色或半透明色块，压在画面边缘。它决定画面的层次和框中框的感觉。

需要时再加：

- **视线方向**：人物看向哪里，在标注层里画一条虚线箭头。
- **地平线或消失点**：街道、走廊这类有纵深的场景，用两三个斜边交代透视方向。
- **需要示意运镜时**，分别画要展示的起点和终点，或在标注层用框示意推到哪里。生图只附对应时刻的小样。

## 不画什么

这些东西小样里不要画，画了没用，还会把生图模型带偏：

- **细节和质感**：脸、五官、表情、衣褶、花纹、建筑构件、灯笼的样子。小样里的人只是剪影，灯只是光斑，模型会按文字去画真的样子。
- **画框里的文字**：标注不要写进画框，否则模型可能把字画进图里。
- **渐变、模糊、发光、投影等特效**：用平涂色块和半透明表示，让模型知道这是示意，不是要照抄的风格。
- **太多元素**：一张小样控制在二三十个形状以内。人群、远处的灯用几个大小不一的色块表示数量感，不要一个一个画。
- **有具体指向的颜色**：衣服、器物的颜色写在文字里。小样里的颜色只表示明暗和冷暖。
- **复杂透视和精确建筑**：只要大方向对。小样画得越精确，模型越容易照着生硬地描。

## 怎么画

- **画框**：按成片比例：16:9 是 1600×900，9:16 是 900×1600，1:1 是 1200×1200。画框下面多留 100 高的标注区，例如 16:9 整张 `viewBox="0 0 1600 1000"`，9:16 整张 `viewBox="0 0 900 1700"`。
- **分两层**：画面层 `<g id="frame">` 只放构图色块，并用 clipPath 裁在画框里，这样故意画出画框的形状（被切掉一半的前景、火盆）不会溢进标注区；标注层 `<g id="labels">` 放画框外的文字、视线箭头。给用户看时两层都显示；附给模型时去掉标注层，只保留画框的范围。
- **用色**：灰阶表示明暗；暖色（如 #e8a050）只用在暖光源和暖光照到的地方；冷色（如 #8fb4e0、#5d7a9e）只用在冷光源和冷光勾的边。半透明的大色块表示虚焦的前景和雾气里的光。
- **给用户看**：能在对话里直接显示 SVG 的就直接显示；不能的，转成图片或存成文件发给用户。转换用当前环境现成的办法。
- **存档**：小样存进项目文件夹，例如 `分镜/构图小样/B7_剪影_小样_v1.svg`；附给模型的图片也放在一起。

## 画完先自查

先自己看一遍（转成图片看，或者在能显示 SVG 的地方看），再给用户。任何一项不对，就改小样、再看一遍：

- **眯眼看**：把眼睛眯起来或缩小看，亮区和暗区一眼分得清；主体没有和背景混成一片。
- **主体大小和位置**：和按焦距、距离算出来的大小对得上；在设计的位置上（例如右三分线）。
- **朝向和姿态读得出来**：侧身、背对、抬手这些，从剪影轮廓上看得出来。
- **层次不打架**：前、中、背景分得开，没有三层叠在同一处；用户第一眼能说出"这是在讲什么"。
- **没有溢出**：所有构图形状都在画框里，没有漏进标注区。
- **干净**：画框里没有字；形状在二三十个以内；没有渐变和特效。
- **和分镜表一致**：左右、站位、视线方向、光源方向都对得上。

## 常用构图骨架

五种骨架的 SVG 在 [构图骨架](composition-skeletons.md)，要画哪种只看哪一节。先按当前镜头确定机位、主体落位、遮挡和明暗，画面关系相符时才取用；其他构图按当前镜头另画。

- **逆光剪影**：主体是暗的，背后满屏虚光，只有一道暖色轮廓光。
- **框中框**：画面大半是暗的门道或窗框，一块偏在一侧的亮口；主体是亮口前的小剪影。
- **前景擦过**：贴着镜头横穿的人虚成一大块，挡住画面中间；擦过之后的样子另画一张。
- **高机位斜线**：屋檐斜切画面，柱子分开两人，地上的阴影线把一人放在光里、一人放在暗里。
- **大负空间里的小人**：人只占画面高度的十分之一左右，放在三分线上；提示词里要写明人很小，否则模型常把人放大。

## 附给生图模型

- 只附去掉标注层的画面层，转成图片。
- 提示词开头写清这张图怎么用，例如：

  > 附图只是一张用平涂色块画的构图和明暗小样。不要照搬它的平面感、形状和颜色。只用它来确定：主体站在哪里、在画面里多大，哪里亮哪里暗，光从哪边来，前景挡住了哪里。按照这个布局，生成一张全新的、符合项目画风的画面。

- 后面接完整的文字描述。小样管不了的都要靠文字写清：人物朝向和视线、动作和表情、服装和材质、建筑和道具的时代特征、光的颜色。
- 小样只附给它对应的目标图片。

## 实际效果（测试结论）

- 带明暗的小样能把人物位置、大小、亮暗分布都定住，模型也不会把它的平面色块感带进成片。
- 只画轮廓线、分割线的最简线稿，能定住位置和大小，定不住明暗：模型把背景画得一样亮，还会自己往空白处添东西。构图靠光讲情绪时，要画明暗。
- 小样管不了朝向和表情。测试里小样只画了站位、文字没写朝向，模型就让人物正对镜头直直站着，显得呆。人物朝向、视线和姿态一定要写进文字；剪影轮廓也要把侧身、抬手这些姿态画出来。
- 小样定不了时代细节。建筑、服饰、灯具的样子仍然靠文字和考据约束。
