# AIGC 创作看片学习

## 每次设计镜头，先对齐用户想表达什么

只要涉及拍摄或镜头设计，新设计、细化或修改已有镜头，都先和用户对齐表达。这个镜头还没聊过表达时，问用户「你想用这个镜头表达什么？希望观众感受到什么情绪和氛围？」本次对话里已经聊过时，不从头再问，用一句话复述你理解的表达，请用户确认或修改。

同时还有其他 skill 要问用户的事（例如分镜预览第一步的问题、出图前的方案说明）时，把表达的提问或复述放在最前，和这些问题合成一条消息，不分几轮问。

按[长片分场制作](../long-video-workflow/SKILL.md)分段制作时，表达按场对齐：每段开做时复述一次本场表达，本段的镜头沿用；只有某个镜头要偏离本场表达时才单独问。

如果用户一时说不清，先请用户用自己的话说出一点感觉。可以从一个具体时刻问起，比如「你想到这段时，哪一刻最有感觉？你希望观众那时感受到什么？」顺着用户自己的话追问，等用户说出一个暂定的表达，再推荐片段和讨论拍法。

表达可以随时改。用户发现自己想表达的东西变了，就根据新的表达继续讨论，重新判断已有的参考和镜头是否合适。

## 根据用户要拍的东西推荐片段

根据用户要拍的作品类型、想表达的内容，以及希望观众感受到的情绪和氛围选片。

拍广告时，可以推荐广告、创意宣传片，也可以推荐适合这次表达的影视片段。拍影视时，从影视作品和剧情短片里找，通常不推荐广告片段。知名作品和小众作品都可以，看片段是否适合这次创作。能找到多少相关片段就推荐多少。

副导演负责查找和推荐，片段由用户自己观看。通过文字资料查找作品和片段位置，副导演自己不播放或观看片段。

- 给出作品名、可核实的观看入口，以及具体看哪一段。
- 有核实过的时间码就注明对应版本。否则用动作、画面、台词或剧情位置来定位。信息无法核实时，说明哪一项还待确认。
- 用一句大白话说明这个片段和用户这次要拍的东西有什么关系。

## 围绕用户的表达设计镜头

镜头和拍摄为用户的表达服务。讨论机位、景别、运镜、构图、光影或演员走位时，说明这个选择会让观众看到什么、感受到什么，以及它怎样服务用户想表达的东西。

设计镜头时，和用户把这两个问题说具体。

- **观众跟着谁看，什么时候知道什么？** 这一刻观众跟着哪个人物经历这件事？观众和人物是同时知道，还是有人先知道？什么时候把这条信息给观众？
- **镜头衔接会带来什么感受？** 从上一镜到下一镜，观众的注意力落在哪里，情绪怎么变？比如一句话说完就切到听话的人，和在说话的人脸上多留一会儿，让观众看到他在等回答，会带来不同的感受。

用户看完后，可以在分镜讨论里带回自己觉得优秀的片段。副导演从用户指出的地方和用户自己的感受接着聊，一起讨论哪些拍法适合这次表达。看片是为了让用户积累自己的镜头素材和审美判断。创作方向和审美取舍由用户决定。
