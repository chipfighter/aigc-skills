# 白模动画

把已聊清的创作意图落实为可修改、可播放、可检查的三维预演。主动设计必要的空间、动作和摄影机安排，利用已有素材与工程。

## 确定制作精度

根据需要控制的关系选择制作程度：

| 控制目标 | 制作程度 |
|---|---|
| 站位、路线、入画时机 | 极简几何体，保证位置、朝向和体积可辨 |
| 特殊姿态、身体与道具关系 | 四肢明确的人形，摆清关键部位与接触位置 |
| 精确抛接、碰撞、支撑或连续动作 | 必要的骨骼、关键姿态与连续运动，可适配已有动作素材 |

静止的特殊姿态也可能需要明确的人形。精度由控制目标决定，不由动作大小决定。

普通动作可以给后续生成留下空间；必须准确发生的过程应提前制作。留意参考中的僵硬动作可能被继承。

## 搭建与编排

- 只搭建影响构图、遮挡和动作路线的结构。已有场景图时围绕它建立可用空间，画外区域按镜头需要补充。
- 人物和重要道具使用稳定身份，不因摄影机改变方向而重新编号。区分固定空间关系与当前画面的左右。
- 移动路线明确起点、转折点、终点和重要到达时间；同时发生的运动放在同一时间线上检查。
- 关键接触表现清楚支撑、受力和状态变化。交接需要连续呈现离手、运动、接触与承接，避免物体直接换位置。
- 摄影机从哪里开始、经过什么、最后看见什么，与人物动作一起安排。只修改摄影机时，保留已确定的表演和站位。

## 预览与修改

先检查开场、中间、结束的构图，再检查完整运动，重点看景别、遮挡、人物位置、路径和动作时机。

复杂部分先做短预览。出现问题时回到对应位置修改：

- 空间、路径或遮挡错误：改工程。
- 动作或接触不成立：改姿态、运动与受力。
- 身份、道具对应错误：查素材对应和交接时间。
- 白模正确而最终生成偏离：再检查参考用途与生成提示词。

同一场景的连续片段尽量在同一工程、同一时间线上安排，再分段导出，检查边界处的动作和道具状态。

## 交付

保留可修改工程，导出主摄影机的可播放预览；时长和画幅与目标片段对齐，并检查实际导出结果。

说明参考分工：人物图提供长相与服装，场景图提供环境外观，白模提供随时间变化的空间与运动关系。明确哪些内容需要保留，哪些粗模外观和僵硬细节不应照搬。
